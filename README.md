# La Pelu SPA — Gestión Integral & Reservas en Patio Bonito, Bogotá

Aplicación web progresiva (PWA / SPA) de alta fidelidad diseñada para **La Pelu SPA**. Integra catálogo de servicios, reserva en intervalos de 1 hora, arqueo de caja y liquidación en pesos colombianos (**COP**), libro de citas, gestión de usuarios autorizados y pasarela de WhatsApp segura.

---

## 🚀 Despliegue en GitHub Pages (Configurado y Corregido)

El flujo de GitHub Actions `.github/workflows/deploy.yml` y `package-lock.json` están listos y optimizados para compilar automáticamente en GitHub.

### 1. Subir los cambios a GitHub
Ejecuta en tu terminal:

```bash
git add .
git commit -m "fix: resolver build de GitHub Actions y dependencias"
git push origin main
```

### 2. Verificar GitHub Pages
- Ve a tu repositorio en GitHub: `https://github.com/sinceof2016/nails-studio`
- Pestaña **Settings** > **Pages**
- **Source**: Asegúrate de tener seleccionado **GitHub Actions**
- Ve a la pestaña **Actions** para ver el despliegue ejecutándose en tiempo real.
